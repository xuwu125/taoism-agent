01 · 设计哲学

仪轨即界面 · 暗坛金纸 · 诚实性优先 · 正交编码 · fail-closed 默认态。详见 docs/05-符箓台设计规范系统.md。

02 · 色板（令牌即规范）

坛面 / 墨色 / 品牌

六终态 · 独立色相，绝不复用

中止（Cancelled）刻意用中性暖灰：它是独立终态，不并入炸炉、不冒充成功、不回滚。把失败折叠成一个红色，界面会诱导用户去查一个不存在的 bug。theme.rs 有单测锁住六色互不相同。

03 · 权限 / 风险正交编码

权限（形状档位）受限执行 风险（色彩）破坏性每次调用 来源 · 未随请求下发
权限是箓层静态上限（ReadOnly / Limited / Full），风险是逐次确认强度（Observe / Mutate / Destructive）。两套编码永不合并成一根危险度滑块。

04 · 诚实性标注原子

估算UNVERIFIED已截断 只读 · 不管理纯展示 · 不判定 非回执已脱敏无人值守 · 一律敕否
