## 4. 已知边界（如实记录）

- **取消的生效时机**：provider 非流式阶段没有增量，点「中止」要等下一个增量才真正断开
  （实测：服务端在数秒后收到断开并 `cancel task`）。这是文档写明的行为，不算缺陷。
- **整符时限 vs 慢推理**：示例符 timeout_secs=60 在 CPU 上必然过坛（事件 5·过坛「推理返回时
  已超过整符时限」）——判据如实，不是 bug； GUI 设置面板新增「请求超时」1..=600 秒可调
  （默认 180），且焚符时被符文 `timeout_secs` 夹小。
- 键入路径（WM_CHAR）对 egui 编辑器不可靠（Ctrl+V/Shift+Insert/逐字符键入均未完整生效），
  载入符文改走「工作区文件 + 点击列表」。IME 真人验收（T37）不受此影响。
- 火光动效（WIN-10/PAP-06）未捕获到 0.9 秒窗口内的画面 → **未验**。
